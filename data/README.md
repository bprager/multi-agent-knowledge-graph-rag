# Input data

SEC data:

- 10-K (Annual Report)
- 10-Q (Quarterly Report)
- 8-K (Current Report)
- 1-SA (Semiannual Report)
- 1-U (Additional Current Report)

for all companies listed in 'ai_companies.yaml' file.

## Note:

The free query limit for the SEC-API is 100 requests per month.
The script will end gracefully it the limit is exceeded.
Visit [sec-api.io](https://sec-api.io) for more information.
